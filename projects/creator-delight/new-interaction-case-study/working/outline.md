# Insight-led outline

1. **Opening transformation** — show the redesigned staged workspace and state the honest outcome level: design and handoff completed; launch impact unverified.
2. **The whole journey was the problem** — connect long form, modals, cost uncertainty, and preview discoverability through the journey map.
3. **Behavioural evidence focused the redesign** — explain Morty’s confirmed Hotjar review without using the unverified 47% claim.
4. **Options made trade-offs discussable** — show workshop collaboration and three design directions without implying sole decision authority.
5. **Testing found the remaining interaction failures** — late incomplete-state feedback, question management, and competing actions.
6. **Precise responses, not a UI gallery** — map each finding to a design change.
7. **Honest outcome and reflection** — delivered handoff, evidence boundary, and a future measurement plan.

## Structure choice

Start with the end for a scanning hiring manager, then use Context–Struggle–Transformation with a clear turning point at prototype testing. This fits the evidence better than the old chronological “first attempt / second attempt” process log.
